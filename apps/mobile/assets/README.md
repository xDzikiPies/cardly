# Assets

Brakuje tu prawdziwych plików graficznych — musisz je dodać sam(a), bo nie generuję obrazków w tym projekcie.

## Wymagane pliki (odwołuje się do nich `app.json`):

- **`splash-icon.png`** — logo Cardly na ekranie startowym. Zalecane: PNG z przezroczystym tłem,
  ok. 400x400px (samo logo, bez tekstu "Cardly" pod spodem — jeśli chcesz tekst, dopisz go w kodzie
  `app/_layout.tsx` jako Text pod obrazkiem zamiast wypalać go w PNG-u, będzie ostrzejszy na każdym ekranie).
- **`icon.png`** — ikona aplikacji (1024x1024px, bez przezroczystości, kwadrat).
- **`adaptive-icon.png`** — ikona adaptacyjna na Androida (1024x1024px, bezpieczny obszar w środkowych ~66%).

Jeśli chcesz, mogę Ci wygenerować/zaprojektować placeholder w kodzie (np. proste logo z inicjałów "C"
w kółku na kolorowym tle) zamiast plików PNG — daj znać.
